# Windows Security Utilities

A collection of PowerShell scripts I developed while preparing for CCDC. The tools focus on Windows security auditing, network activity inspection, and scheduled task enumeration.

## Tools

* **PowerShell Auditing:** Configures PowerShell logging for security monitoring.
* **Network Connection Inspector:** Collects TCP and UDP endpoint information and associated process details.
* **Scheduled Task Inspector:** Enumerates scheduled tasks outside selected default Microsoft paths to assist with manual security review.

## Purpose

These scripts were created as personal preparation tools. They are intended for defensive security learning and administration in authorized Windows environments.
